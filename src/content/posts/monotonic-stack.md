单调栈我一直记不住，直到把这三道题并排写了一遍。模板本身只有一句话：**栈里存的是"还在等答案的下标"**。

## 模板

```go
func nextGreater(nums []int) []int {
    ans := make([]int, len(nums))
    for i := range ans {
        ans[i] = -1
    }
    stack := []int{} // 存下标，对应值从栈底到栈顶单调递减

    for i, x := range nums {
        for len(stack) > 0 && nums[stack[len(stack)-1]] < x {
            j := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            ans[j] = x // 唯一需要按题意改的一行
        }
        stack = append(stack, i)
    }
    return ans
}
```

## 三题的差别只在弹出时做什么

| 题目 | 弹出时机 | 弹出那一行写成 |
| --- | --- | --- |
| 496 下一个更大元素 I | 遇到更大值 | `ans[j] = x` |
| 739 每日温度 | 等到更高温度 | `ans[j] = i - j` |
| 84 柱状图最大矩形 | 遇到更矮的柱子 | `area = h * (i - 栈顶 - 1)` |

739 和 496 只差在存值还是存下标；84 则是把单调性反过来（栈里维护递增），并且要额外处理"弹出后左边界是新的栈顶"这一步。

## 一个反复踩的坑

Go 里 `stack = stack[:len(stack)-1]` 只是移动长度，被弹出的元素仍然引用着底层数组。这题不影响正确性，但在写单测断言时会看到奇怪的结果——建议每次 push 前显式判断 `len`，别用 `append` 的返回值做越界访问。

下次遇到"下一个更大/更小/距离"字样，先默写这个模板，再决定那一行填什么。
