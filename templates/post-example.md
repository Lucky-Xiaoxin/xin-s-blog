导语：这篇只解决一个问题——为什么区间和可以 $O(1)$ 查，以及写代码时最容易错在哪。读完你应该能独立写出预处理和查询两段。

## 问题

> 给定长度为 $n$ 的数组 $a$，回答 $m$ 次询问：$\sum_{i=l}^{r} a_i$。

朴素做法每次都要扫一遍区间，$m$ 次询问就是 $O(nm)$。

## 前缀和

### 定义

令

$$
S_k=\sum_{i=1}^{k}a_i,\qquad S_0=0
$$

那么区间 $[l,r]$ 的和就是

$$
\sum_{i=l}^{r}a_i=S_r-S_{l-1}
$$

一句话：**用两个前缀和相减，把求和变成一次减法。**

### 预处理与查询

先扫一遍数组，再把每次查询压到一行。

```cpp
vector<long long> s(n + 1, 0);
for (int i = 1; i <= n; ++i) s[i] = s[i - 1] + a[i];

// 查询 [l, r]，下标从 1 开始
long long range_sum(int l, int r) {
    return s[r] - s[l - 1];
}
```

如果原数组下标从 0 开始，查询前先把 `l`、`r` 各加一。

## 三个容易错的地方

- 前缀和数组开 `n + 1`，并且让 `s[0] = 0`
- 查询写 `s[r] - s[l - 1]`，不是 `s[r] - s[l]`
- 和可能超过 `int`，前缀和数组用 `long long`

## 复杂度

| 做法 | 预处理 | 单次查询 | 空间 |
| --- | --- | --- | --- |
| 朴素 | $O(1)$ | $O(n)$ | $O(1)$ |
| 前缀和 | $O(n)$ | $O(1)$ | $O(n)$ |

## 小结

前缀和的本质是**把重复的加法预先存下来**。看到“数组不变、多次区间查询”就先想它；数组会改，再换树状数组或线段树。

更系统的推导可以看 [OI Wiki 的前缀和一章](https://oi-wiki.org/basic/prefix-sum/)。
