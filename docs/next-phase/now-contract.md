# now 页契约

> 状态：已批准 · 2026-10-23；按本文与 `design-contract.md` 执行，实现中验证。
> 已确认：做 **碎碎念 + now**；其它作者生活层功能（友链、评论、统计、Newsletter、点赞、Webmention）**暂不做**。

## 1. 一句话定义

`/now/` 是“**我最近在干嘛**”的静态页：现在在学什么、做什么项目、读什么、生活状态如何。它不是文章，也不是 about。

## 2. 与其它页面的区别

| 页面 | 回答的问题 | 更新方式 |
| --- | --- | --- |
| `/about/` | 我是谁、这个站写什么 | 很少改，稳定介绍 |
| `/now/` | 我最近在做什么 | 每月或状态变化时改，覆盖旧内容 |
| `/notes/` | 今天/这两天发生了什么 | 随时追加，带时间戳，不覆盖 |
| `/posts/...` | 一个完整主题的论述 | 写完发布，长期保留 |

判断标准：**长期稳定的自我介绍 → about；当前状态 → now；带时间的小事 → notes；完整论述 → 文章。**

## 3. 内容模型

建议新增 `pages` collection，文件 `src/content/pages/now.md`：

```yaml
---
title: '现在'
description: '最近在学什么、做什么。'
updatedDate: 2026-10-22
draft: false
---
## 在学
CSAPP 第 6 章、概率论。

## 在做
- 给博客补归档和碎碎念
- 准备蓝桥杯

## 在读
《深入理解计算机系统》……

## 最近
每周三晚上更新一次；最近在折腾字体子集。
```

> 上面只是“完整分节”的示例，不是首版内容。2026-10-23 用户已定首版为单行状态 `emo中……`、正文为空；实现细节见 `p1b/content-model.md` §7.2。

规则：

- `updatedDate` 必填，页面显示“最后更新于 YYYY.MM.DD”；与文章 `updatedDate` 同一套 UTC 渲染，避免时区少一天。
- `title` / `description` 必填；`title` 固定为“现在”即可；**首版 `description` 为用户定的单行状态 `emo中……`**。
- 正文可以为空：首版 `/now/` 只显示页头（标题/单行状态/最后更新），不渲染正文区。
- 如果写正文，用 Markdown；建议 4–6 个小节（在学/在做/在读/最近），每节 1–3 条，总量控制在 1 屏左右。
- 支持链接、行内代码、图片；图片必须有 alt。
- 不做标签、不做 RSS、不做评论、不做点赞。
- 不做历史版本页；旧版本看 git history 就够。
- 不要写成日记；带日期的小事去 `/notes/`。

## 4. URL 与导航

- 路由：`/now/`。
- 导航：**不单独占主导航**（保持 目录 / 归档 / 标签 / 关于 四项）；从 `/about/`、页脚、`/notes/` 进入。
- 首页：在页边 notes 下方放一行 now（设计方向一）；不单独占首屏块，不与碎碎念抢位置。
- sitemap：包含 `/now/`；不生成 RSS item；不做 `BlogPosting` 结构化数据（它不是文章）。
- 页面标题：`现在 · 二进制与诗`；description 用 frontmatter 的 `description`。

## 5. 更新流程

1. 编辑 `src/content/pages/now.md`。
2. 改 `updatedDate`。
3. `npm run dev` 看效果。
4. push 到 main（内容更新，按现有“写文章直推 main”的双轨处理；首次新增页面属于框架改动，走分支/PR）。

频率建议：每月一次，或“在学/在做”发生明显变化时。不要为了显得勤快而硬更新。

## 6. 设计契约

- 它是“作者在场”的页面，不是简历；语气可以比 about 更口语。
- 沿用现有设计语言：白底、正红、几何线、Bodoni + 思源宋体、mono meta；不引入新配色。
- 必须有“最后更新于”的 meta；可以有一个小的状态点/几何标记，但不能变成仪表盘。
- 亮/暗两态、320px、打印、键盘焦点都要成立。
- 零 JS；不做滚动动画、不做进度条。

## 7. 非目标

- 从 GitHub / 豆瓣 / Goodreads 自动同步。
- 多个 now 页面、now 历史归档、now RSS。
- 评论区、点赞、访客留言。
- 把 now 做成任务管理/进度仪表盘。
- 在 now 里放长文；长文写成文章。

## 8. 已确认默认（2026-10-22）

| 编号 | 决定 |
| --- | --- |
| W1 | 用 `pages` collection（Markdown）；以后 about 也可迁移，编辑更省心 |
| W2 | 首页页边 notes 下方放一行 now；不单独占首屏块 |
| W3 | 小节（在学 / 在做 / 在读 / 最近）为**可选**；首版正文为空，只有单行状态 |
| W4 | 每月或状态变化时覆盖更新；不强制 |
| W5 | 不占主导航；从 about/页脚/notes 进入，避免导航过挤 |
| W6 | **2026-10-23 用户已定首版内容**：`description: 'emo中……'`，`draft: false`，正文为空；`updatedDate` 填实际发布日 |
