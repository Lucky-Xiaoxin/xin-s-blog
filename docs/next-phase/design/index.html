结论先行

选一个，不要三个一起上

建议方向一「卷首」作为 P1 主线。它最直接地补上首页第一屏、文章节奏和编辑感，改动集中在版式与数据层，不引入新依赖，也最容易在现有 Astro 结构里拆成小 PR。若更看重“作者在场”，选方向三「页边」；若更想强化技术身份，选方向二「测绘」。方向三的“此刻”一行可以单独借到方向一里。

01

卷首

把首页做成一册目录的卷首：第一屏是本期最新、页边碎碎念和“现在”，而不是一张空白的几何图。

A 首页第一屏 B 阅读节奏 D 编辑感 C 页面壳 零新增 JS

它做什么

  • 首页：几何图缩成“本册索引”（文章/碎碎念/现在），下面开卷 + 页边 + 目录编号。
  • 文章：页边放印记与规格，内联目录，小节编号，题记、图注、代码标题栏、延伸阅读。
  • 页面壳：归档按年月 + 编号；标签成为“标签索引”；碎碎念按月成流；now 是状态页。

它牺牲什么

首页从单列变两栏，移动端碎碎念落在开卷之后、目录之前；文章头比现在高一点；目录是内联块，不是 sticky 侧栏（遵守 P0）。

落地要点

  • 复用现有 prose / code / tag / seal / pager。
  • 新增首页 frontmatter、内联目录、归档与 notes/now 路由。
  • JS 0；主题开关沿用现有。

MOBILE ARTICLE

头部压缩：页边规格只留“归档 / 印记”，目录前移；正文在窄屏自然回落，仍保持 42rem 的阅读逻辑。

02

测绘

把站点做成一张可测量的技术图纸：几何图变成带标注的测绘图，所有内容都有编号、刻度和索引。

A 首页第一屏 B 阅读节奏 D 内容密度 C 页面壳 零新增 JS

它做什么

  • 首页：三形状变成带引线的测绘图；下面接近期索引、日志、状态。
  • 文章：ISSUED / READ / CLASS / SEAL 标题块，目录带引导线，正文左侧量尺，NOTE / FIG / LISTING 编号。
  • 页面壳：归档寄存器、标签图例、碎碎念日志、now 状态单。

它牺牲什么

信息密度最高，也最容易偏冷；320px 下测绘图标注会隐藏、日志只留 2 条，标题块和目录会把正文推到第二屏。碎碎念在桌面走右栏、与文章列表并排，移动端才移到上方；这是与默认契约的一处偏差，需确认。

落地要点

  • CSS 即可完成，但标题块、量尺和寄存器需要新结构。
  • 测绘图 SVG 约 2.5KB；移动端隐藏微缩标注。
  • JS 0；全部编号由构建期生成。

MOBILE ARTICLE

移动端隐藏测绘图标注，日志只留 2 条；标题块折成 2×2，目录行高压缩，尽量把正文提前。

同一套色板，更强的网格与标注

COLOR TOKENS

与方向一相同：纸、墨、正红、规则线、面。红色只用于最新标记、编号和当前状态；其余靠 1px / 3px 双线与等宽标签建立层级。

TYPE & RHYTHM

标题 Bodoni + 思源宋体；正文 17px / 1.9，measure 42rem；正文左侧 3rem 量尺；标签与刻度 9–11px 等宽；标题块用 4 列网格。

COMPONENTS

测绘板 · 标题块 · CONTENTS 引导线 · 左侧量尺 · NOTE / FIG / LISTING 标签 · 寄存器 · 图例 · 日志 · 状态单 · 双线规则。

落地说明

方向二
现有 CSS 可完成令牌、prose、代码、表格、标签、印记、分页与 .scroll-x；量尺可通过正文左边框 + h2 负边距实现，无需 JS。
需要新结构测绘 SVG + 标注层；文章标题块（4 格 dl）；CONTENTS 列表；正文量尺；归档寄存器、标签图例、日志、状态单。数据仍是 posts/notes/now 三类。
新增 JS0。所有编号、日期、阅读时长在构建期算好；主题切换沿用现有脚本。
新资源测绘图 SVG 约 2.5KB；无位图、无新字体族。字号极小的小标签（9–10px）只用于 meta，不承载正文信息。
预算方向 CSS 约 3.5KB gzip 上限；当前 12.9KB → ≤16.4KB；JS 0；仍在 runtime-contract 预算内。
风险 / 注意密度和冷感是主要风险；短文章会被标题块+目录压住，建议移动端把目录行高再压缩。若读者以“读文章”为主，这个方向需要克制使用全大写标签。

03

页边

把正文保持在 42rem，把 now、碎碎念和目录放进页边；像一册有铅笔批注的读书笔记。

A 首页第一屏 B 阅读节奏 C 作者在场 D 编辑感 零新增 JS

它做什么

  • 首页：导航下先放“此刻”，最近在写；页边承载 3 条碎碎念和现在；文章目录在手机上前移到列表之上。
  • 文章：标题页 + 贯通全篇的页边（印记/规格/目录）；摘录在页边标注；正文仍是 42rem。
  • 页面壳：日记式碎碎念、信件式 now、阅读日志式归档、书签式标签。

它牺牲什么

布局工作量最大：贯通页边要处理 56–60rem 的中间宽度；移动端需要重新排序；页边目录不是 sticky（遵守 P0），滚动后会离开视口。

落地要点

  • 文章用 grid-area：head / margin / body，页边在桌面贯穿全篇，手机折成 head → margin → body。
  • 首页在移动端用 order + display:contents 把碎碎念放到文章列表之前。
  • JS 0；只有版式与 SVG 边饰。

MOBILE ARTICLE

页边折成 head → margin → body：规格列隐藏，目录仍在正文之前；首页的碎碎念也会前移到文章列表之上。

组件与令牌

暖意来自语气与留白，不靠新颜色

COLOR TOKENS

仍是纸、墨、正红、规则线、面；没有暖黄、没有纸纹、没有渐变。层次靠 1px 竖线、页边留白和衬线标题。

TYPE & RHYTHM

正文 42rem / 17px / 1.95；页边 13rem；标题页与页边目录使用 Bodoni + 思源宋体；日期用衬线，时间与刻度用等宽。

COMPONENTS

此刻一行 · 页边装饰 · 页边碎碎念 · 贯通页边 · 页边目录 · 摘录页边签 · 日记流 · 信件式 now · 阅读日志 · 书签列表。

落地说明

方向三
现有 CSS 可完成令牌、prose、代码、表格、标签、印记、上下篇、焦点与 .scroll-x；页面壳大多是现有排版的重组。
需要新结构文章 grid-area（head / margin / body）；首页“此刻”行 + 页边块 + 移动端重排；碎碎念/now/归档/标签的新版式。数据仍是 posts/notes/pages 三类。
新增 JS0。移动端重排靠 CSS order + display:contents；主题切换沿用现有脚本。
新资源页边装饰 SVG 约 0.7KB；无位图。衬线新增用例（页边日期、月份）需要纳入字体子集扫描来源。
预算方向 CSS 约 3.5KB gzip 上限；JS 0；无新字体族；仍是 18KB gzip 预算内。
风险 / 注意56–60rem 是页边布局的临界带，必须在 768 / 1024 两档实际看；页边目录不 sticky，长文滚动后只能靠回顶；移动端已把规格列隐藏以让正文上移。

验收与边界

对应 design-brief 第 5 节与 runtime-contract

IDENTITY

仍然是白底、单一正红、几何描边、Bodoni + 思源宋体；没有换配色、没有圆角卡片堆、没有图库照片。Seal 映射与 TAG_SHAPE 未动。

READING

正文 measure 保持 42rem；技术内容继续走 .scroll-x；目录、图注、代码标题栏、摘录都服务于跳读，而不是装饰。

IMPLEMENTATION

三个方向都是静态 HTML/CSS，无新依赖；JS 0。字体子集、明暗双入口、打印、KaTeX/MathML 与 .scroll-x 的约束全部保留。

ACCESSIBILITY

320 / 375 / 768 / 1024 / 1440，亮/暗，禁用 JS；焦点红框、TOC 锚点、标签热区、notes 锚点；装饰 SVG 全部 aria-hidden。

SELF-CHECK

3 方向 × 7 页 × 5 宽度 × 亮/暗共 147 次，加上总览页 3 次，共 150 次自动检查，0 个问题；36 张截图（含总览页）；报告在 screens/audit.json。

NOT CHANGED

不改 URL、不改 Seal、不改字体加载策略、不设计系列、不引入第三方、不写生产代码。文章页用现有文章摘录 + 版式示例块，notes/now 为示例文案；未改动 src/content。所有原型都在 docs/next-phase/design/。
