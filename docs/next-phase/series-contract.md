# 系列（Series）契约（暂缓）

> 状态：暂缓 · 2026-10-23。本文只定义语义与契约，不包含实现。
> **2026-10-22 决定：暂缓，不进入 P0/P1。** 现有 4 篇不足以形成有序连载；本文保留作未来参考，等内容成组后再评估。

## 1. 一句话定义

**系列 = 一组有明确阅读顺序、建议从头读到尾的文章。** 单篇可以独立成立，但按顺序读会得到一条完整的学习/实践路径。

关键词：**有序、有目标、有起点和终点**。

## 2. 它不是什么

| 概念 | 语义 | 例子 |
| --- | --- | --- |
| 系列 | 有序连载，顺序有意义 | `CSAPP 陪读`：第 1 章 → 第 2 章 → … |
| 标签 | 无序、横切分类，一篇可多个 | `算法`、`工具`、`GitHub` |
| 专栏/专题 | 无序主题集合，本质是“带说明的标签页” | `算法题解`：每篇独立，顺序不重要 |
| 目录/归档 | 按时间或站点结构浏览 | `/archive/` |

**判断标准**：如果把文章顺序打乱，读者会不会漏掉前置知识、看不懂？会 → 系列；不会 → 标签/专栏。

## 4. 数据契约

frontmatter 只加两个可选字段，现有文章零迁移：

```yaml
series: 'csapp'       # 稳定 key：小写字母/数字/连字符，进入 URL
seriesOrder: 10       # 系列内顺序：正整数，系列内唯一；允许留空号（10/20/30）便于插入
```

规则：

1. `series` 与 `seriesOrder` 必须同时出现；只写一个 → 构建报错。
2. 一篇最多属于一个系列。需要横切归类时用标签，不要塞进多个系列。
3. `series` 是稳定 key，**改名等于换 URL**；中文标题可以改，key 不要改。
4. `seriesOrder` 只在系列内比较，不要求连续；重复 → 构建报错，并打印冲突文件名。
5. 草稿不进入 build 的系列页/计数；dev 是否显示带标记的草稿，见待定项。

## 5. 系列注册表

在 `src/const.ts` 增加显式注册表（与 `TAG_SHAPE` 同一哲学：单一事实源、允许手改）：

```ts
export const SERIES = {
  csapp: {
    title: 'CSAPP 陪读',
    description: '按章节重读 CSAPP，记下课件没讲透的地方。',
    status: 'ongoing', // ongoing | complete
  },
  'build-blog': {
    title: '从零搭这个博客',
    description: '从空白仓库到上线，记录每个取舍。',
    status: 'complete',
  },
} as const;
```

- `title` 用于 UI；`key` 用于 URL。
- `description` 用于系列索引页与文章系列横幅的 tooltip/说明；不写也行，但建议写。
- 未注册的 `series` key → 构建报错，并提示去 `SERIES` 登记。
- 注册表只增不减；删除系列前必须先处理旧 URL（本阶段不做重定向）。

## 6. URL 与页面

| 路由 | 内容 |
| --- | --- |
| `/series/` | 系列索引：标题、说明、篇数、状态、最近更新；按注册表顺序或最近更新排序 |
| `/series/[key]/` | 系列目录：说明 + 按 `seriesOrder` 排序的文章列表；当前篇高亮 |
| `/posts/[slug]/` | 文章页：系列横幅 + 系列内上下篇 + 返回系列 |

文章页系列横幅（建议位置：文章头部 meta 之后、正文之前）：

```
系列 · CSAPP 陪读 · 第 2/8 篇        [查看系列 →]
```

系列目录页不混入无关文章；标签仍可在系列文章上正常使用。

## 7. 校验规则（构建期）

- `series` 未在 `SERIES` 注册 → 失败。
- 有 `series` 无 `seriesOrder`，或有 `seriesOrder` 无 `series` → 失败。
- 同系列 `seriesOrder` 重复 → 失败，列出两个文件名。
- `seriesOrder` 非正整数 → 失败（schema 已限制）。
- 系列 key 必须匹配 `^[a-z0-9][a-z0-9-]*$`，避免 URL 编码与大小写歧义。
- 系列页文章数 = 该系列已发布文章数；草稿不计入。
- 系列索引页若没有任何已发布系列，是否生成空页？建议不生成，导航也不显示入口。

## 8. 非目标

- 一篇多系列。
- 系列嵌套（大系列套小系列）。
- 系列级 RSS（后续可加，不在本阶段）。
- 系列专属主题/配色。
- 按日期自动排序替代显式 `seriesOrder`。
- 单独的“专栏/专题”内容类型；无序集合先用标签页增强（描述、置顶）解决。
